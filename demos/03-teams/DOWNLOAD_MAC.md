# Bot Framework Emulator - Mac Download Instructions

## 📥 Download for Mac

I tried to download it automatically, but here's the easiest way:

### Option 1: Direct Download (Recommended)

1. **Open this link in your browser:**
   ```
   https://github.com/microsoft/BotFramework-Emulator/releases/latest
   ```

2. **Scroll down to "Assets" section**

3. **Download the `.dmg` file** (look for `BotFramework-Emulator-*-mac-*.dmg`)

4. **Open the downloaded `.dmg` file**

5. **Drag Bot Framework Emulator to Applications**

### Option 2: Using Homebrew (If you have it)

```bash
brew install --cask botframework-emulator
```

### Option 3: Manual Download Script

Run this in terminal:

```bash
cd ~/Downloads
open "https://github.com/microsoft/BotFramework-Emulator/releases/latest"
```

Then download the `.dmg` file from the page that opens.

## 🚀 After Download

1. **Open the `.dmg` file** (double-click it)
2. **Drag Bot Framework Emulator to Applications**
3. **Open Applications folder**
4. **Launch Bot Framework Emulator**

## ✅ Verify Installation

Once installed, you should be able to:
- Find "Bot Framework Emulator" in Applications
- Launch it from Spotlight (Cmd+Space, type "Bot Framework Emulator")

## 🔗 Quick Links

- **Latest Release:** https://github.com/microsoft/BotFramework-Emulator/releases/latest
- **All Releases:** https://github.com/microsoft/BotFramework-Emulator/releases

## 💡 Note

Microsoft has announced Bot Framework Emulator will be retired by end of 2025, but it still works perfectly for testing! The replacement is "Agents Playground" but Emulator is still the standard tool for now.
