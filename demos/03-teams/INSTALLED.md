## ⚠️ Note About Rosetta 2

If you're on an Apple Silicon Mac (M1/M2/M3), you may see a message about Rosetta 2. 

**If the app doesn't launch**, install Rosetta 2:
```bash
softwareupdate --install-rosetta --agree-to-license
```

This is a one-time setup and allows Intel apps to run on Apple Silicon Macs.
