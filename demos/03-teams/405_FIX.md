# Teams Bot - 405 Error Fixed

## ✅ Issue Resolved

The 405 error occurred because:
- Bot Framework endpoint `/api/messages` only accepted POST requests
- GET requests (like from browser or health checks) returned 405

## 🔧 Fix Applied

Added health check endpoints:
- `GET /` - Health check
- `GET /api/messages` - Health check with helpful message
- `POST /api/messages` - Bot Framework endpoint (unchanged)
